# 새 게임 음악 시안: Acoustic Percussion

## 요청

기존 게임곡을 폐기하고 전자음 느낌을 줄인 피아노·실로폰 등 타악기 중심의 새 음악 요청. 대기곡은 범위 밖.

## 시안 15

- `15-game-acoustic-percussion-136bpm.mp3`: 136 BPM, 24마디, 약42.35초.
- 새 멜로디, 마림바 중심 + 짧은 피아노 화음 + 낮게 섞인 실로폰 + 봉고/우드블록/셰이커.
- 실제 녹음 샘플을 피치 변경·편집해 배열했다. 현장 합주 녹음은 아니며 기존 코드의 합성 파형 악기는 사용하지 않는다.
- 낮은 음역과 짧은 잔향, 정박 기반. 지속 베이스·신스·전자 드럼 없음.
- 샘플: [Versilian Community Sample Library](https://versilian-studios.com/vcsl/), CC0. 개별 원본 경로는 `sources.json`.
- 재생성: `node docs/music-demos/2026-09-20/make-acoustic.mjs` (Node, ffmpeg, curl, 네트워크 필요). 샘플은 /tmp에 캐시되며 저장소에 복제하지 않는다. WAV는 로컬 렌더 원본이며 MP3만 배포용 시안으로 보관.

## 현재 상태

사용자 청취용 시안. 아직 게임에 연결하지 않았으며 대기곡·효과음·게임 코드는 변경하지 않았다. 오디오 변경만으로 화면 비교는 해당 없음. 기존 승인곡보다 낫다는 주관적인 청취 평가는 사용자 확인이 필요하다.
