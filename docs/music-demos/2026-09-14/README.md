# TAPtoTALK 배경음악 청취 시안

## 새 제안 — 대기 V4 + 게임 V3

- [대기 Sunny Stroll](06-lobby-sunny-stroll-v4-128bpm.mp3): 128 BPM,31.2초. 동물의 숲 같은 포근하고 발랄한 일상 분위기를 요청받아 별도 작곡. 해당 게임 음악·멜로디·샘플을 사용하지 않았다. G장조의 새 선율, 정박/균등8분음표, 부드러운 중음역, 낮은 기타풍 분산화음, 정박 북/발소리와 작은 셰이커. V3의 긴 쉼·엇박 중심 구성을 교체했다.
- [게임 Jamo Dance Soft](07-game-jamo-dance-soft-v3-136bpm.mp3): 136 BPM,43.55초. 선호한 V2의 음표·타이밍·편곡은 유지하면서 현악 어택을 둥글게, 고음 탭과 slap의 gain을 낮췄다. 원음은 보존했다.

재생성은 `make-lobby-v4.mjs`와 `make-game-v3.mjs`에 새 출력 폴더를 전달한다. 전자는 lowpass4200Hz, threshold0.16/ratio2/attack10/release120 압축, 후자는 lowpass3400Hz, threshold0.09/ratio4/attack2/release80/makeup2 압축. 둘 다 loudnorm I−19/TP−2/LRA7 후44.1kHz·192kbps MP3로 인코딩했다. 정상 디코딩·길이·피크 확인. 모든 소리는 합성 시안이며 실제 악기 녹음이 아니다. 청취 취향은 사용자 평가로 확인한다.

아직 게임 미적용. 이전 초안과 다른 저장소는 변경하지 않았으며 화면 변경이 없어 스크린샷은 해당 없음.

## 대기용 V3 — Soft Steps

[120 BPM 부드러운 대기용 시안](05-lobby-soft-steps-v3-120bpm.mp3)

V2가 느리고 ‘띵띵’ 소리가 튄다는 피드백을 반영했다. 108→120 BPM, 약33.2초. 주선율은 한 옥타브 내리고, 노이즈로 시작하는 짧은 현악 합성을 부드러운35ms 어택·낮은 배음·긴 음가의 중음역 음색으로 교체했다. 고음 중복 선율 제거, 관악 응답도 한 옥타브 낮추고 탭·북은 작게 조정했다. 별도 새 파일이며 이전 시안과 게임곡은 그대로다.

재생성: `make-lobby-v3.mjs <새-출력폴더>`. FFmpeg `lowpass=f=3000,acompressor=threshold=0.16:ratio=2:attack=10:release=120,loudnorm=I=-19:TP=-2:LRA=7` 후44.1kHz 스테레오192kbps MP3로 인코딩. 정상 디코딩·길이·피크 확인. 사용자의 실제 청취로 편안함을 확인할 시안이며 아직 게임에 연결하지 않았다.

## 대기용 V2 — Hangul Courtyard

[새 대기용 시안 듣기](04-lobby-hangul-courtyard-v2-108bpm.mp3)

새 게임용 V2에 대한 긍정적 피드백 이후 대기용도 요청받아 새로 작곡했다. 108 BPM, 약36.76초,16마디. 게임곡의 저속 재생이 아니라 C/D/F/G/A 음계의 별도 선율이다. V2 현악·관악·타악 합성 엔진은 공유하되 멜로디의 여백을 늘리고 북·탭의 횟수와 세기를 줄였다. 스윙, 피아노식 코드 반주, 움직이는 베이스는 없다.

`make-lobby-v2.mjs <새-출력폴더>`로 재생성하며 게임용 V2와 같은 컴프레서·음량 정규화 설정으로44.1kHz 스테레오192kbps MP3를 인코딩한다. 길이·정상 디코딩·피크를 확인했다. 실제 국악기 녹음이 아닌 합성 청취 초안이며 게임에 미적용, 무봉제 루프도 아직 아니다. 이전 시안은 모두 보존한다.

## 게임용 V2 — Jamo Dance

[새 게임용 시안 듣기](03-game-jamo-dance-v2-136bpm.mp3)

사용자가 첫 시안을 TAPtoTEN과 너무 비슷하다고 평가해 게임용을 새로 작곡했다. 단순 속도 변경이 아니다. 136 BPM, 약43.55초, 24마디, 스윙 없는 리듬. 피아노·코드 반주·움직이는 베이스를 제거하고 짧은 반복/문답 선율, 낮고 높은 북 합성음, 탭 타격을 사용한다. 딜레이 라인 기반 현악 합성으로 첫 시안의 종소리 같은 음색도 바꿨다. 전통 장단이나 실제 국악기 녹음을 재현한 것은 아니다.

`make-game-v2.mjs <새-출력폴더>`로 WAV 재생성. 청취 MP3는 순간 피크를 완화하기 위해 FFmpeg `acompressor=threshold=0.09:ratio=4:attack=2:release=80:makeup=2,loudnorm=I=-19:TP=-2:LRA=7` 처리 후44.1kHz·192kbps로 인코딩한다. 정상 디코딩 확인. 정량 확인만 수행했으며 음악적 선호는 사용자 청취로 판단한다.

기존 두 시안과 다른 게임 저장소는 그대로 보존. 새 버전도 아직 게임에 연결하지 않았고 반복 재생용 마감은 승인 후 진행한다.

사용자 요청: TAPtoTEN·TAPtoPICK의 대기/게임 구분과 발랄한 템포를 참고하되 다른 음악 두 곡. 탭댄스 리듬 또는 한글 게임에 어울리는 국악 느낌.

실제 가야금·장구·탭슈즈 녹음이 아닌 **절차적 작곡과 합성 악기 시안**이다. 전통 장단을 재현한 곡이 아니라 국악 현악을 연상시키는 가벼운 음색을 현대 퍼즐게임 리듬에 섞었다. 외부 음원·샘플·멜로디는 복사하지 않았다. 두 시안도 서로 다른 선율과 조성을 사용한다. 전문 음악 생성 서비스는 사용하지 않았다.

## 참고한 자료

다른 저장소는 읽기만 했다. 실제 음원을 청취했다고 간주하지 않으며, 다음 제작 명세·작곡 코드·장면 전환 코드로 확인한 사항이다.

- TAPtoTEN `docs/music-demos/2026-09-14/README.md`, `make-demos.mjs`, `src/ui/musicSceneFor.ts`: 대기112 / 게임124 BPM, 짧은 선율·탭 리듬, 영상·일시정지는 무음.
- TaptoPick `public/assets/audio/README.md`, `pick-tap-lobby.json`, `pick-garden.json`: 대기136 BPM 스윙·탭, 게임100 BPM 말렛. 대기곡과 게임곡은 별도 작곡.

## 파일·검증

44.1kHz 스테레오16bit WAV 합성 후 FFmpeg192kbps MP3 인코딩. 정상 디코딩과 파일 길이를 확인했다. 합성 WAV 피크 상한0.72, RMS는 각각 약−19.05 / −19.24dBFS. 정량 검증은 청취 품질 평가를 대체하지 않으며 선호와 반복 피로도는 사용자 청취로 확인한다.

WAV 중간 파일은 `/private/tmp/talk-music-aphE19`에 두고 MP3와 재현 스크립트만 저장소에 둔다. 다시 만들 때 새 출력 폴더를 사용:

```sh
node docs/music-demos/2026-09-14/make-demos.mjs <새-출력폴더>
```

현재 파일은 끝맺음과 잔향이 있는 청취용이며 무봉제 루프가 아니다. **게임에 적용하지 않았고 실행 코드·배포 화면·다른 게임은 수정하지 않았다.** 승인 후 반복 경계·음량·대기/플레이 전환·영상 재생 중 정지·모바일 첫 탭 재생을 별도로 작업한다. 화면 변경이 없어 전후 스크린샷은 해당 없음.
