# YYYY-MM-DD 주요 변경 기록

## 변경 제목

- 적용 커밋: `abcdef0`
- 비교 커밋: `1234567`
- 재현 여부: 성공 / 실패
- 비교 조건: 모드, 진입 행동, 기타 조건

### 문제·개선 요구

무엇이 불편하거나 부족했는지 적는다.

### 수정 내용과 이유

무엇을 왜 선택했는지 적는다.

### 수정 결과

사용자에게 보이거나 동작하는 차이를 적는다.
