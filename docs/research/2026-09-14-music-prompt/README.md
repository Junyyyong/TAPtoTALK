# 2026-09-14 음악 안내 스타일 통일

- TAPtoPICK의 메인 하단 `Tap for music` 문구, 17px 스피커 SVG, 13px 고딕 글씨, 44px 고정 안내 자리와 포커스 스타일을 TAPtoTALK에 적용했다.
- 자동재생 차단 시에만 안내하는 기존 조건과 Music/Sound 설정 이름·기능은 유지했다. 다른 저장소는 읽기만 했다.
- 빌드 및 diff 공백 검사 통과.
- Chrome에서 메인은 실제로 menu/playing 상태였다. 자동재생 차단 조건 재현을 시도했으나 안내가 노출되지 않아, 안내를 강제로 표시한 이미지는 만들지 않았다. 안내 클릭 검증은 완료하지 못했다.
