# 2026-09-16 후속 어휘 정리

사용자 요청에 따라 전화번호와 같은 '전화'가 반복되는 휴대전화를 휴대폰으로 교체했다. 영어 뜻 mobile phone은 유지한다. 글자 수가 바뀌므로 4글자 풀에서 3글자 풀로 이동했다.

전체89개는 동일하며 추가 어휘는 3글자21개 / 4글자17개 / 5글자19개다. 앞으로 신규 복합명사는 기존 단어와 같은 구성어가 불필요하게 반복되지 않는지 확인한다. 이번에는 사용자가 지정한 휴대전화만 교체했다.

단일 콘텐츠 교체로 화면 구조 변경은 없으며 별도의 전후 화면은 추가하지 않았다. 회귀 테스트에서 휴대폰의 뜻·3글자 분류·휴대전화 제외 및 전체 단어의 연속 조합을 검증한다.
