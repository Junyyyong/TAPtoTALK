## 캡처 표준

- 뷰포트: 390×844 CSS px
- 배율: 2배
- PNG 결과물: 780×1688 px
- 브라우저: 로컬 Google Chrome Headless
- 과거 소스: `git archive <commit>`으로 `/private/tmp`의 독립 폴더에 추출
- 비교 원칙: 같은 모드와 같은 사용자 행동을 우선하며, 화면 흐름 자체가 바뀐 경우 그 차이를 기록
- 금지: 과거처럼 보이도록 현재 화면을 임의 편집하거나 합성하지 않음

## 앞으로의 기록 방식

주요 게임 규칙, 화면 구조, 디자인 시스템, 콘텐츠 체계 또는 미디어 흐름을 바꾸는 작업에는 [기록 템플릿](TEMPLATE.md)을 사용한다. 코드 커밋 번호, 요구 배경, 변경 이유, 결과, 동일 조건의 전·후 화면을 함께 남긴다. 사소한 오탈자나 단일 자산 교체는 필요할 때만 기록한다.

재현 캡처 도구는 [`tools/capture-mobile.mjs`](tools/capture-mobile.mjs)이며 게임 번들에는 포함되지 않는다.
