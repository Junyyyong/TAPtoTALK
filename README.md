# TAP to TALK

자모 타일을 탭하며 한글의 낱자부터 단어와 문장까지 익히는 모바일 게임입니다.
TAP to TEN의 화면 감각과 웹/Android 빌드 기반만 복사했으며, 원본 저장소에는 push할 수 없도록 설정했습니다.

## 현재 프로토타입

- Alphabet: `ㄱ`부터 `ㅎ`, `ㅣ`, `ㅡ`, `ㆍ`까지 2×2에서 하나씩 찾고, 4×4에서는 3개씩, 6×6에서는 5개씩 순서대로 누르는 연속 학습 여정
- 전체 스테이지 수는 게임 화면에 노출하지 않으며, 자음은 해당 자소 자체의 눈에 보이는 좌우·상하반전 또는 90° 회전만, 선 모음은 굵기가 같은 세 사선, 아래아는 별·하트·쉼표 보기로 구분
- 아래아 `ㆍ`의 역사적 음가는 국립국어원 자료에 따라 추정음 `[ʌ]`로 안내
- `ㅇ`은 꼭지이응 `ㆁ`, 여린히읗 `ㆆ`, 쌍이응 `ㆀ`을, `ㅁ`은 순경음미음 `ㅱ`, `△`, `○`을 보기로 사용
- 메인 게임 이름은 Alphabet, Word, Sentence로 통일하고 Alphabet 진입 전에는 TAP to TEN 흐름과 맞춘 간단한 START 화면을 제공
- 음절 학습의 쌍자음은 완성 블록 대신 `ㄲ=ㄱ+ㄱ`처럼 기본 자음을 반복하고, 겹받침도 `읽=ㅇ+ㅣ+ㄹ+ㄱ`처럼 낱자 단위로 입력
- 문장 따라쓰기: 목표 문장에 필요한 자모를 보장한 81타일
- 단어 학습: 받침 없음, 받침 있음, 감탄사, 의성·의태어, 복모음의 다섯 단계에서 세 단어씩 완성
- 보드에는 기본·쌍·격음 자음 19종, 천지인 `ㆍ`, `ㅡ`, `ㅣ`, 문장부호 `.`, `!`, `?`를 배치
- 하단 고정 버튼은 Space와 Delete만 제공
- 문장부호가 필요 없는 단어 자판은 문장부호 대신 일부 여분 자음을 좌우·상하반전하거나 90° 회전한 함정으로 배치하며, 누르면 `×` 오입력이 된다
- 목표에 필요한 문장부호도 보드의 독립 블록으로 배치
- 목표 자소 수의 약 1.5배를 보장해 오입력 후에도 다시 찾을 여유 제공
- 하단 고정 버튼은 띄어쓰기와 삭제만 사용
- 입력 토큰 단위 되돌리기
- 문장 따라쓰기는 레벨별 무작위 3문장 누적 시간, 단어 도전은 단계별 3단어 누적 시간으로 평가
- 성공 시 기존 `1`, `4`, 태피, 후피, 해피, 재피 중 하나를 무작위로 재생하고 실패 시에는 티피를 재생
