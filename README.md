# TAP to TALK

자모 타일을 탭하며 한글의 낱자부터 음절과 단어까지 익히는 모바일 게임입니다.
TAP to TEN의 화면 감각과 웹/Android 빌드 기반만 복사했으며, 원본 저장소에는 push할 수 없도록 설정했습니다.

## 현재 프로토타입

- Alphabet은 2×2 → 4×4 → 6×6까지, Syllable은 2×2 → 4×4까지 시간·점수 제한 없는 PRACTICE다. 크기별 구간 완료마다 GREAT! 영상 후 탭으로 진행한다.
- Alphabet은8×8부터, Syllable은6×6부터60초 본게임이 시작된다. Syllable은 첫1분 종료·영상·탭 후8×8로 전환하고 이후 유지한다. Word는 처음부터8×8·60초다. 영상과 일시정지 중에는 시간이 흐르지 않는다.
- Alphabet은 완성한 제시어 묶음당150점, 상한 없음(10문제1500, 11문제1650). Syllable 20음절 / Word 10단어가1500점이며 두 게임의 상한1500은 유지한다. 오입력·미완성·튜토리얼에는 점수가 없고 별도 보너스도 없다.
- 시간 종료 후 점수 2초 → 등급 영상 → 탭으로 다음 1분 라운드. 완료 수는 초기화하고 콘텐츠 순서는 이어간다. 기록 저장은 아직 구현하지 않았다.

- Alphabet: `ㄱ`부터 `ㅎ`, `ㅣ`, `ㅡ`, `ㆍ`까지 2×2에서 하나씩 찾고, 4×4에서는 3개씩, 6×6에서는 5개씩 순서대로 누르는 연속 학습 여정
- 블록은 사용자 `탭투톡체.svg` 도형을 코드에 포함해 개별 SVG 다운로드 없이 표시한다. 전체 스테이지 수는 노출하지 않으며, 일반 자음 함정은 중심 기준 90°·180°·270° 회전이다. ㄹ은 중복 방지를 위해 반전과 90° 회전을 조합한다. ㅍ은 세로획 1개·3개와 90° 회전, ㅣ·ㅡ만 반대 방향 직선과 ±45° 사선, 아래아는 별·하트·쉼표를 사용한다.
- 아래아 `ㆍ`의 역사적 음가는 국립국어원 자료에 따라 추정음 `[ʌ]`로 안내
- `ㅇ`은 꼭지이응 `ㆁ`, 여린히읗 `ㆆ`, 쌍이응 `ㆀ`을, `ㅁ`은 순경음미음 `ㅱ`, `△`, `○`을 보기로 사용
- 함정이 현재 제시 자소와 같은 모양이 되는 경우 제외한다. 예: ㄱ·ㄴ의 180° 회전, ㅇ 제시 시 ㅁ의 원형 함정. Alphabet 제시어창은 자소 개수와 관계없이 같은 높이를 유지한다.
- 메인은 Alphabet → Syllable → Word 순서이며 세 게임 모두 ㄱ·가·안녕 아이콘이 있는 START 화면으로 진입
- Alphabet의 고정 학습 뒤에는 무작위 세 자소를 찾는 8×8 판이 끝없이 이어짐. 일반 자소 전체와 약 20% 함정을 함께 배치
- Syllable: 2×2 가~하14개 → 4×4 기본모음10·복모음11·쌍자음5·기본받침14·겹받침/쌍받침13개. 총67문제에서 모음21종·쌍자음5종·받침27종을 경험한다. 본게임은 배운 목록에서 무작위 출제한다.
- Word 조합은 제시어에 의존하지 않는다. 연속 ㄷㄷ+모음은 ㄸ 초성으로 합쳐진다. 걷→Space→Delete→도는 걷도를 유지하지만 같은 자소를 연속 입력하면 거또가 된다. 공백 삭제 후 내부 확정 경계를 보존한다.
- 음절 학습의 쌍자음은 완성 블록 대신 `ㄲ=ㄱ+ㄱ`처럼 기본 자음을 반복하고, 겹받침도 `읽=ㅇ+ㅣ+ㄹ+ㄱ`처럼 낱자 단위로 입력
- 긴 문장 따라쓰기는 메뉴와 활성 화면 흐름에서 제거 (이전 문장 데이터·테스트는 이력 호환용으로 보존)
- Word: 받침 없음 → 받침 있음 → 감탄사 → 의성·의태어 → 복모음 순으로 기존 33단어를 하나의 코스로 통합. 레벨 선택 없이 한 단어가 한 스테이지
- Word는 8×8(64개) 보드에 기본 자음 14종과 천지인 `ㆍ`, `ㅡ`, `ㅣ`를 배치한다. 쌍자음은 ㄱ+ㄱ처럼 기본 자음을 반복 입력하며 완성 쌍자음 블록은 나오지 않는다. 목표에 필요한 문장부호만 별도로 사용한다.
- Word 하단 Space는 현재 입력을 확정하고 실제 공백을 추가한다. Delete는 공백만 지워도 확정 경계를 유지한다. 남아 있는 내부 공백은 정답에서 무시하지 않는다(걷 도≠걷도). 공백과 보이지 않는 확정 경계는 자소 입력 용량·점수에서 제외한다.
- 문장부호가 필요 없는 단어 자판은 일부 여분 자음을 90° 단위로 회전한 함정으로 배치하며, 누르면 `×` 오입력이 된다. 회전 대칭인 ㄹ·ㅍ은 정답과 같은 모양이 되지 않도록 제한한다.
- 목표에 필요한 문장부호도 보드의 독립 블록으로 배치
- 목표 자소 수의 약 1.5배를 보장해 오입력 후에도 다시 찾을 여유 제공
- 하단 고정 버튼은 띄어쓰기와 삭제만 사용
- 입력 토큰 단위 되돌리기
- Word는 고정 33개 이후 새 단어로 진행: STAGE 34–43은 3글자, 44–53은 4글자, 54부터는 5글자 무작위 반복. 각 길이별 새 단어 20개(총 60개)는 기존 33개와 겹치지 않음
- Word 단어 순서는 라운드 사이에도 유지한다. 같은 길이의 단어는 한 묶음을 소진하기 전 재등장하지 않고 새 묶음 첫 단어도 직전 단어와 다르게 선택한다. 미완성 단어는 다음 라운드에서 다시 입력한다.
- 이전 Word의 10문제마다 자동 보너스는 제거했다. 영상 오류·재생 차단 시에도 탭 대기로 전환하며, 최대 영상 대기는 15초다.
- Alphabet은 고정 27개, Syllable은 고정 67개 이후 무작위 스테이지가 계속 이어짐. 세 게임 모두 메뉴로 종료 가능
- 등급별 영상: NOT BAD(0) 티피, GOOD TRY(1–299)·GREAT(300–599) 1, AMAZING(600–999) 4, UNBELIEVABLE(1000–1399) 태피/후피, OH MY GOD(1400 이상) 해피/재피.

## CI와 APK 다운로드

push/PR에는 테스트·웹 빌드·Android 빌드만 실행하고 APK 파일은 저장하지 않는다. 설치파일이 필요할 때 GitHub **Actions → CI → Run workflow**에서 **Save the debug APK for download**를 켜고 실행한다. 생성된 APK는 7일간 보관한다. 기존 artifact 저장공간이 가득 찬 상태라면 수동 저장 전에 공간 확보가 필요하다.

## Git 원격 설정

- `origin`: `Junyyyong/TAPtoTALK` — 이 프로젝트의 fetch/push 원격
- `source`: `Junyyyong/TENtoTAP` — 원본 참조용 fetch 원격, push는 `DISABLED`
