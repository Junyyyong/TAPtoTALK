# TAP to TALK

자모 타일을 탭하며 한글의 낱자부터 음절과 단어까지 익히는 모바일 게임입니다.
TAP to TEN의 화면 감각과 웹/Android 빌드 기반만 복사했으며, 원본 저장소에는 push할 수 없도록 설정했습니다.

## 현재 프로토타입

- Alphabet: `ㄱ`부터 `ㅎ`, `ㅣ`, `ㅡ`, `ㆍ`까지 2×2에서 하나씩 찾고, 4×4에서는 3개씩, 6×6에서는 5개씩 순서대로 누르는 연속 학습 여정
- 전체 스테이지 수는 게임 화면에 노출하지 않으며, 자음은 자기 자소를 90°·180°·270° 회전한 보기로 구분한다. ㄹ은 좌우·상하반전과 90° 회전, ㅍ은 세로획 1개·3개와 90° 회전을 사용한다. ㅣ·ㅡ는 반대 방향 직선과 ±45° 사선, 아래아는 별·하트·쉼표를 사용한다.
- 아래아 `ㆍ`의 역사적 음가는 국립국어원 자료에 따라 추정음 `[ʌ]`로 안내
- `ㅇ`은 꼭지이응 `ㆁ`, 여린히읗 `ㆆ`, 쌍이응 `ㆀ`을, `ㅁ`은 순경음미음 `ㅱ`, `△`, `○`을 보기로 사용
- 메인은 Alphabet → Syllable → Word 순서이며 세 게임 모두 ㄱ·가·안녕 아이콘이 있는 START 화면으로 진입
- Alphabet의 고정 학습 뒤에는 무작위 세 자소를 찾는 8×8 판이 끝없이 이어짐. 일반 자소 전체와 약 20% 함정을 함께 배치
- Syllable은 가 → 나 → 다부터 한 음절씩 천지인으로 조합하며 2×2 → 4×4 → 6×6 → 무작위 8×8로 진행
- 음절 학습의 쌍자음은 완성 블록 대신 `ㄲ=ㄱ+ㄱ`처럼 기본 자음을 반복하고, 겹받침도 `읽=ㅇ+ㅣ+ㄹ+ㄱ`처럼 낱자 단위로 입력
- 긴 문장 따라쓰기는 메뉴와 활성 화면 흐름에서 제거 (이전 문장 데이터·테스트는 이력 호환용으로 보존)
- Word: 받침 없음 → 받침 있음 → 감탄사 → 의성·의태어 → 복모음 순으로 기존 33단어를 하나의 코스로 통합. 레벨 선택 없이 한 단어가 한 스테이지
- 보드에는 기본·쌍·격음 자음 19종, 천지인 `ㆍ`, `ㅡ`, `ㅣ`, 문장부호 `.`, `!`, `?`를 배치
- 하단 고정 버튼은 Space와 Delete만 제공
- 문장부호가 필요 없는 단어 자판은 문장부호 대신 일부 여분 자음을 좌우·상하반전하거나 90° 회전한 함정으로 배치하며, 누르면 `×` 오입력이 된다
- 목표에 필요한 문장부호도 보드의 독립 블록으로 배치
- 목표 자소 수의 약 1.5배를 보장해 오입력 후에도 다시 찾을 여유 제공
- 하단 고정 버튼은 띄어쓰기와 삭제만 사용
- 입력 토큰 단위 되돌리기
- Word는 고정 33개 이후 새 단어로 진행: STAGE 34–43은 3글자, 44–53은 4글자, 54부터는 5글자 무작위 반복. 각 길이별 새 단어 20개(총 60개)는 기존 33개와 겹치지 않음
- Word도 제한시간과 최종 결과 없이 누적 시간을 표시하며 계속 진행. 같은 길이의 단어는 한 묶음을 소진하기 전 재등장하지 않고 새 묶음 첫 단어도 직전 단어와 다르게 선택
- Alphabet은 고정 27개, Syllable은 고정 82개 이후 무작위 스테이지가 계속 이어짐. 세 게임 모두 메뉴로 종료 가능
- 성공 시 기존 `1`, `4`, 태피, 후피, 해피, 재피 중 하나를 무작위로 재생하고 실패 시에는 티피를 재생
